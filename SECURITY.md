# Politique de sécurité

Merci de nous aider à protéger les utilisateurs d'Itera.

## Signaler une vulnérabilité

**Ne créez pas d'issue publique.** Utilisez le signalement privé de GitHub
(onglet *Security* → *Report a vulnerability*) de ce dépôt.

Merci d'indiquer : la version / plateforme concernée, les étapes de reproduction, l'impact
estimé. Nous accusons réception sous 72 heures et vous tenons informé·e jusqu'à la
correction. Merci de nous laisser un délai raisonnable (90 jours max.) avant toute
divulgation publique.

## Périmètre

Application iOS, application web et code de ce dépôt. Le modèle de menaces et les mesures
en place sont décrits dans [docs/SECURITE.md](docs/SECURITE.md).
