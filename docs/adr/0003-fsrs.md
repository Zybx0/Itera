# ADR-0003 — Algorithme de planification FSRS (ts-fsrs)

- Statut : accepté (2026-09-25)

## Décision
Utiliser FSRS-6 via `ts-fsrs`, isolé derrière `packages/core/src/scheduler/fsrs.ts`.
L'état FSRS est stocké sous forme sérialisable (`Schedule`) et chaque révision conserve
l'état précédent (`scheduleBefore`) pour permettre l'annulation et, plus tard,
l'optimisation des paramètres sur l'historique.

## Alternatives
SM-2 (ancien Anki) : plus simple mais nettement moins efficace (plus de révisions pour la
même rétention).
